# Roadmap de Implementacao - FocoMax

Este roadmap organiza as melhorias em fases curtas, com foco em impacto real para o usuario.

## Fase 1 - Experiencia diaria (concluida)
Objetivo: deixar o app mais util no dia a dia, com menos friccao para iniciar foco.

- [x] Saudacao inteligente por horario (bom dia, boa tarde, boa noite)
- [x] Atalhos de foco rapido (15, 25 e 50 minutos)
- [x] Priorizacao clara das 3 tarefas principais do dia
- [x] Alerta de tarefas atrasadas no painel de hoje
- [x] Sugestao automatica local (coach por regras)
- [x] Check-in matinal em 1 toque (humor, energia e foco)
- [x] Replanejamento rapido de tarefas atrasadas
- [x] CTA de retomada de sessao interrompida

## Fase 2 - Controle de distracoes e disciplina
Objetivo: reduzir interrupcoes durante execucao de foco.

- [x] Modo foco profundo (UI simplificada + menos toques)
- [x] Bloqueio de apps distracao no Android (modo de acessibilidade)
- [x] Integracao com modos de concentracao no iOS (atalhos/sugestoes)
- [x] Registro de interrupcao com motivos favoritos
- [x] Pausas inteligentes baseadas no historico do usuario
- [x] Deteccao de abandono de sessao + fluxo de recuperacao

## Fase 3 - Planejamento inteligente
Objetivo: transformar tarefas em execucao consistente.

- [x] Meta diaria adaptativa de foco
- [x] Priorizador automatico de tarefas criticas
- [x] Reagendamento assistido (atrasadas -> nova janela)
- [x] Sugestoes por melhor horario de execucao
- [x] Relacao tarefa x energia (evitar tarefas longas em baixa energia)

## Fase 4 - Progresso e coach avancado
Objetivo: mostrar evolucao clara e orientar ajustes de rotina.

- [x] Relatorio semanal simples (o que funcionou / o que ajustar)
- [x] Insights de comportamento (horarios bons e ruins)
- [x] Correlacao humor x foco x conclusao
- [x] Queda de consistencia com alertas preventivos
- [x] Recomendacoes praticas acionaveis

## Fase 5 - Premium muito superior
Objetivo: diferenciar forte o Premium por valor real.

- [x] Coach avancado completo com plano semanal personalizado
- [x] Analises comparativas e tendencias de longo prazo
- [x] Relatorios premium exportaveis (PDF/CSV)
- [x] Temas premium, microinteracoes e acabamento visual superior
- [x] Desafios premium com progressao estruturada
- [x] Remocao permanente de anuncios + controles finos

## Fase 6 - Confiabilidade e ecossistema
Objetivo: estabilidade, retencao e facilidade de uso continuo.

- [x] Backup local automatico com versao e restauracao segura
- [x] Widget de foco rapido na tela inicial (via card rapido + deep link de atalho)
- [x] Atalhos de sistema (iniciar foco, registrar humor)
- [x] Melhorias de acessibilidade (fonte, contraste, area de toque)
- [x] Suite de testes para fluxos criticos (onboarding, foco, backup)

## Metricas de sucesso por fase

- Fase 1: mais sessoes iniciadas por dia, menor abandono na tela Hoje.
- Fase 2: menos interrupcoes por sessao, maior taxa de conclusao.
- Fase 3: menos tarefas atrasadas, mais tarefas concluidas no prazo.
- Fase 4: aumento de consistencia semanal e retorno diario.
- Fase 5: conversao para premium e retencao premium.
- Fase 6: menos erros em producao e melhor confiabilidade percebida.
